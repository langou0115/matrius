# 开发文档索引

本目录从 `../matrius-old/doc/` 迁移，保留产品、认证、数据存储、Agent、文件与记忆约定，客户端实现说明按 React + Vite Web 维护。

## 当前进度与阅读方式

- 当前只维护 Web 界面；移动 Web 响应式适配后续按单独要求进行。
- Web 已完成聊天外壳、侧栏、会话管理、标题/正文搜索、外观设置和本地 Agent Runtime；旧版 10 套配色与字体已迁入。
- 当前为单用户实例：业务数据统一保存到后端，浏览器仅保存模型配置、密钥和设备状态。用户管理与本地/云端切换已移除，未登录时显示实例登录入口。
- 后端接口、数据契约与部署见 [后端架构](backend.md) 和 [服务器部署](deployment.md)；客户端实现入口见 `client-structure.md`，迁移步骤见 `migration.md`。
