# UI 风格与交互规范

[文档索引](README.md) · [代码修改入口](client-structure.md)

本文件保留旧版已确定的界面设计。当前先实现 Web 聊天外壳与外观设置，移动端后续适配；Web 已实现 Markdown、公式与代码高亮；连续选区实测和真实生成仍需后续验证。修改 UI 前先读这里；设计决定变化时同步更新对应规则和代码。

## 整体风格

- 以 Twitter 风格的圆角、简洁排版和扁平层次为基础。默认配色为 Twitter；侧栏采用紧凑的品牌、操作、会话列表与用户入口布局。
- 暗色采用深灰而非纯黑背景，侧栏、主区域、输入框和弹出卡片通过明度区分层次；正文用浅灰，辅助文字保证可读，不依靠过低透明度弱化。Web 链接使用原生锚点配合 Expo Router，避免默认 Text 样式带入黑字。
- 配色主题只改变颜色，布局、字体、间距、组件形状保持一致。不要读取配色预设的 `radius` 改变圆角。
- 业务组件通过统一主题 hooks 取色，通过共享形状常量取圆角，不直接写业务颜色。
- 减少装饰性分界线、阴影和重复入口。聊天顶栏与消息区之间没有横线，顶栏右侧没有设置按钮；设置统一从侧栏底部用户行进入，以独立全页显示，不覆盖或嵌在聊天区域中；对话区右上角不显示运行模式。
- 聊天区域保持透明，顶栏使用不透明页面背景；输入框上方和两侧上部留白透明，底部遮挡从输入框下圆角起点延伸到页面底边，覆盖左右下圆角外侧缝隙及底部 24px 留白，使用不透明页面背景遮挡滚动消息；输入框轮廓内保留主题的轻背景。顶栏会话标题最多显示 360px，窄屏随可用空间收缩，单行溢出显示省略号，保留完整标题文本。
- 按钮不显示悬停文字说明，仍保留无障碍名称、焦点反馈和键盘操作能力。
- 应用统一关闭可视 Tooltip。图标按钮通过 React Native 无障碍属性提供名称与角色，不能仅依赖 Tooltip，否则关闭提示时会一并丢失无障碍名称。

## 布局与尺寸

以下尺寸作为 React Native 布局单位的迁移基准，需适配安全区、字体缩放与窄屏；部分为后续目标，实际入口见客户端结构。

| 项目 | 目标规格 | 目标组件职责 |
| --- | --- | --- |
| 侧栏宽度 | 260 | 侧栏容器 |
| 桌面侧栏/手机抽屉切换 | 960 | 聊天布局 |
| 侧栏条目左右边界 | 12 | 侧栏条目布局 |
| 侧栏条目最小高度 | 44 | 侧栏条目布局 |
| 会话条目垂直间隔 | 8 | 侧栏条目布局 |
| 搜索与收缩按钮间隔 | 12 | 侧栏头部 |
| 聊天顶栏高度 | 52 | 聊天顶栏 |
| 正文与输入区最大宽度 | 760，内部左右留白各 24 | 消息区与输入区 |
| 输入框距离页面底部 | 24，保持一行小字高度的空白，不放说明文字 | 输入框 |
| 发送/停止按钮 | 36 × 36，圆形 | 发送/停止按钮 |

目标组件归属 `src/features/chat/`，实际创建后在[客户端结构](client-structure.md)登记。36 × 36 是按钮视觉尺寸，移动端需扩展触摸命中区，侧栏操作也须保证易于触达。

桌面 Web 端右侧采用整栏原生滚动容器，轨道覆盖整栏高度，顶栏和输入框通过 sticky 保持固定；滚动条轨道宽 14px，滑块两侧各留 2px 间距，颜色跟随主题，支持 WebKit 滚动条样式的浏览器显示上下箭头按钮，Firefox 使用系统标准滚动条；移动端使用平台滚动体验，并处理键盘避让和底部安全区。滚动实际改变消息列表位置。侧栏滚动与消息滚动独立，代码横向滚动不驱动右侧滚动条。

## 侧栏

- 侧栏品牌行和对话区顶栏共用 52px 高度与顶部起点，垂直居中对齐；空白新对话不在顶栏重复显示“新对话”。
- 侧栏滚动条单独采用 10px 轨道、6px 滑块，与会话条目之间保留 8px 间距，Firefox 使用细滚动条；保留上下箭头，聊天区继续使用 14px 轨道。新对话和历史条目共享这份间距，保持轮廓对齐。
- 顶部品牌与右侧搜索、收缩按钮对齐，搜索和收缩按钮间距为 4px，窄屏进一步收紧。搜索和收缩图标不做旋转、缩放或位移动画。
- 侧栏收起后，聊天顶栏左侧距边缘 16px 显示单独的展开胶囊按钮：视觉尺寸 48 × 36，点击区域 48 × 44；22px 简洁分栏图标、低对比细边框与统一大号圆角，颜色跟随主题。悬停轻微加深底色与边框，按下提供底色反馈，保持位置与尺寸稳定。胶囊内只保留展开侧栏操作，支持键盘焦点且不显示 Tooltip。
- 新对话与历史会话使用同一个滚动容器和内容宽度，左右轮廓严格对齐；新对话入口在列表顶部固定，不随历史记录滚走。按钮最小高度 44px，使用 18px 写入图标、中等字重及与历史条目相同的圆角；采用中性底色与细边框，悬停与按下逐步加深，不改变尺寸。与历史会话保持 24px 间距。
- 已选中会话使用中性灰底，不能使用用户消息的浅蓝底。颜色由侧栏前景色以 8% 混合到侧栏底色；普通悬停采用 4%。
- 侧栏没有会话时，在历史对话列表区域内水平、垂直居中显示浅灰色虚线对话图标和“暂无历史对话”，不显示分组标题或其他引导文案；颜色跟随明暗主题。
- 历史会话标题前不显示图标，置顶状态通过分组区分；标题直接左对齐、单行省略，不显示消息数量。仅溢出的标题在悬停或键盘聚焦时，在约 150ms 后以 35px/秒往返展示全称，末尾停留 450ms；离开后恢复省略。开启减少动态效果时改为手动横向滚动。三点菜单在桌面悬停、键盘聚焦或菜单打开时显示，窄屏中直接显示；预留按钮空间，不让标题和行宽跳动。
- 三点按钮旁弹出紧凑的小卡片，卡片左边缘对齐按钮左边缘，靠近视口边缘时自动避让；包含置顶/取消置顶、重命名、删除三个选项；点击外部或按 Esc 关闭。选中重命名后再打开标题输入弹窗，选中删除后再打开确认弹窗。菜单项悬停使用清楚可见的圆角中性底色，删除文字和图标保留危险色。置顶会话单独分组；重命名不能保存空标题；删除需确认。
- 搜索打开独立弹窗，匹配标题与消息正文；结果显示会话标题，正文命中时附必要片段。选择结果后关闭弹窗并进入该会话。
- 底部用户行不显示设置图标，整行可点击进入设置页，不再添加第二个设置入口或侧栏深浅色切换按钮。

## 消息与输入框

- 用户消息右对齐，使用浅蓝色气泡；颜色由主题主色以 16% 混合到页面背景，深色模式使用相同规则得到低亮度蓝底。文字使用正文前景色。
- AI 回复下方常显复制、赞、踩、分支四个图标，桌面按钮 28px、间距 2px，触屏保持 44px 点击区域；赞与踩互斥，可再次点击取消。用户气泡下方仅显示复制图标，桌面悬停或键盘聚焦时显现，触屏常显。工具栏预留高度，不因显隐导致消息跳动，不显示 Tooltip，保留无障碍名称。
- 消息复制使用完整原文，成功短暂显示勾选，失败通过状态和图标颜色反馈；分支从选中 AI 回复（含本条）复制此前上下文到新会话并切换，保留原会话。
- 助手回答左对齐、无气泡，正文和代码块沿统一内容宽度排版。用户与助手共用 Markdown/GFM 和 KaTeX 渲染；标题、引用、列表与表格通过字号和留白建立层次，表格与块级公式在窄屏内独立横向滚动。
- 代码块顶部显示语言，右侧只显示复制和收起/展开图标，不显示操作文字；默认展开，复制成功短暂显示勾选图标。操作保留键盘焦点和无障碍名称，触屏点击区域至少 44px，不显示 Tooltip。代码原文可横向滚动，高亮颜色仅随浅色/深色模式切换。
- 输入框使用轻背景、细边框与固定圆角，不加明显阴影。焦点只改变边框颜色，不改变边框宽度或布局。
- 输入框从 2 行起步，最多扩展到 8 行，再由输入框内部滚动。底部工具栏右对齐，模型选择器位于发送/停止按钮左侧，间距 10px。
- 输入非空内容后，发送按钮下一帧立即启用；清空或仅空白时立即禁用。生成中同一按钮位置变成停止。
- 桌面键盘 Enter 发送，Shift + Enter 换行；移动端软键盘保留换行，通过发送按钮提交。中文输入法组合过程中 Enter 用于确认候选，不误发送。这些快捷键不在输入框下方显示。
- 发送后清空输入并保留焦点。停止生成保留已生成内容；操作侧栏不应让正文突然跳动。

## 字体、圆角与选区

| 场景 | 字体与规格 |
| --- | --- |
| 正文 | Inter，中文回退 Noto Sans SC；15px，行高 1.6 |
| 侧栏标题 | 正文系列，14px，单行 |
| 代码块 | JetBrains Mono，中文回退 Noto Sans SC；13px，行高 1.55 |
| 基础圆角 | 大号圆角 20.8，来自 Twitter 的 1.3rem 基准 |
| 其他圆角 | 小号 16.8、中号 18.8、大容器 24.8；统一由共享形状常量管理 |

- 字体随应用打包，不依赖系统字体或在线字体请求。
- 用户消息与助手回答使用统一的文本选择与复制适配。Web 目标为同一回答跨块连续选择；原生端保留系统选区与整条消息复制，具体能力单独验证。Web 正文使用文本光标，按钮使用点击光标。
- 中英文和代码按各自文字规格使用固定行高；选区色在主题层预合成为不透明色，避免不同容器底色改变选中效果。
- 行内代码保留在正文文本流中，用等宽字体区分；避免嵌入导致复制丢字的独立组件，不叠加遮挡选区的文字底色。
- 代码语言标签、复制和折叠按钮不参与正文选区，复制不能混入工具栏文字。

## 修改与验证

- 先调整对应组件或统一 token，再更新本文；不要在不同页面复制同一套尺寸常量。
- 检查浅色、深色、桌面与窄屏。特别检查条目宽度、弹窗、焦点、菜单可达性、输入法、选区和滚动轨道。
- 静态检查与相关测试按 [开发与验证](development.md) 执行。浏览器/Web 实测和截图不作为常规 UI 修改步骤；仅在用户明确要求时执行。
- 当前 Web 已实现会话管理、搜索、输入框、字体和 10 套配色；生成尚未接入，因此不展示停止按钮或模拟回复。Web 对话与外观偏好已存入浏览器，App 本地存储与原生富文本仍待实现，跨段落选区需浏览器实测。
