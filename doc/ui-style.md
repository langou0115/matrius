# UI 风格与交互规范

[文档索引](README.md) · [代码修改入口](client-structure.md)

本文件保留旧版已确定的界面设计。当前只实现 Web 聊天外壳与外观设置，移动 Web 适配后续再做；Web 已实现 Markdown、公式与代码高亮；连续选区与真实服务商的浏览器行为仍需后续实测。修改 UI 前先读这里；设计决定变化时同步更新对应规则和代码。

## 整体风格

- 以 Twitter 风格的圆角、简洁排版和扁平层次为基础。默认配色为 Twitter；侧栏采用紧凑的品牌、操作、会话列表与用户入口布局。
- 暗色采用深灰而非纯黑背景，侧栏、主区域、输入框和弹出卡片通过明度区分层次；正文用浅灰，辅助文字保证可读，不依靠过低透明度弱化。Web 链接使用原生锚点配合 Expo Router，避免默认 Text 样式带入黑字。
- 配色主题只改变颜色，布局、字体、间距、组件形状保持一致。不要读取配色预设的 `radius` 改变圆角。
- 业务组件通过统一主题 hooks 取色，通过共享形状常量取圆角，不直接写业务颜色。
- 模型与服务商的品牌 logo 使用 `@thesvg/react`（theSVG）的彩色 SVG，按品牌匹配并保留原始填色与渐变，不自行绘制或用图标库替代；附件文件类型使用本地 Material Icon Theme 原色 SVG（`public/vendor/file-icons/`，包含来源版本与 MIT 许可证），Word、Excel、PPT、PDF、Markdown 和常见代码、压缩、音视频格式分别匹配专用图标，未知格式回退文档图标；通用界面图标（编辑、删除、添加、展开、复制等）使用 `lucide-react`，线宽统一 1.75，颜色跟随 `currentColor`。不在 `icon.tsx` 中新增手绘路径，改动涉及的旧图标逐步迁移到 lucide。
- 减少装饰性分界线、阴影和重复入口。聊天顶栏与消息区之间没有横线，顶栏右侧没有设置按钮；设置统一从侧栏底部用户行进入，以独立全页显示，不覆盖或嵌在聊天区域中；对话区右上角不显示运行模式。
- 聊天区域保持透明，顶栏使用不透明页面背景；输入框上方和两侧上部留白透明，底部遮挡从输入框下圆角起点延伸到页面底边，覆盖左右下圆角外侧缝隙及底部 24px 留白，使用不透明页面背景遮挡滚动消息；输入框轮廓内保留主题的轻背景。顶栏会话标题最多显示 360px，窄屏随可用空间收缩，单行溢出显示省略号，保留完整标题文本。
- 按钮不显示悬停文字说明，仍保留无障碍名称、焦点反馈和键盘操作能力。
- 应用统一关闭可视 Tooltip。图标按钮通过 React Native Web 的无障碍属性提供名称与角色，不能仅依赖 Tooltip，否则关闭提示时会一并丢失无障碍名称。

## 布局与尺寸

以下尺寸作为布局基准；移动 Web 适配时再处理窄屏、字体缩放与安全区。部分为后续目标，实际入口见客户端结构。

| 项目 | 目标规格 | 目标组件职责 |
| --- | --- | --- |
| 侧栏宽度 | 260 | 侧栏容器 |
| 桌面侧栏/手机抽屉切换 | 960 | 聊天布局 |
| 侧栏条目左右边界 | 12 | 侧栏条目布局 |
| 侧栏条目最小高度 | 44 | 侧栏条目布局 |
| 会话条目垂直间隔 | 桌面 2 | 侧栏条目布局 |
| 侧栏主导航与历史区域间隔 | 8 | 侧栏布局 |
| 聊天顶栏高度 | 52 | 聊天顶栏 |
| 首条消息到聊天顶栏 | 20 | 消息区布局 |
| 正文与输入区最大宽度 | 780，内部左右留白各 24 | 消息区与输入区 |
| 输入框距离页面底部 | 24，保持一行小字高度的空白，不放说明文字 | 输入框 |
| 发送/停止按钮 | 36 × 36，圆形 | 发送/停止按钮 |

目标组件归属 `src/features/chat/`，实际创建后在[客户端结构](client-structure.md)登记。36 × 36 是按钮视觉尺寸；移动 Web 适配时需扩展触摸命中区，侧栏操作也须保证易于触达。

桌面 Web 端右侧采用整栏原生滚动容器，轨道覆盖整栏高度，顶栏和输入框通过 sticky 保持固定；滚动条轨道宽 14px，滑块两侧各留 2px 间距，颜色跟随主题，支持 WebKit 滚动条样式的浏览器显示上下箭头按钮，Firefox 使用系统标准滚动条；移动 Web 需单独处理滚动、键盘避让和底部安全区。滚动实际改变消息列表位置。侧栏滚动与消息滚动独立，代码横向滚动不驱动右侧滚动条。

## 侧栏

- 侧栏品牌行和对话区顶栏共用 52px 高度与顶部起点，垂直居中对齐；主导航紧跟品牌行，只留 4px 间距，让 Matrius 与新对话读作一组；空白新对话不在顶栏重复显示“新对话”。
- 侧栏会话滚动条使用上下箭头按钮和与聊天区相同的滑块样式，轨道收窄到 12px 并贴近侧栏右缘，与会话行之间留出约 6px 空隙；不为轨道常驻预留一整列空白。主导航、分组和会话标题共享 12px 内边距。
- 顶部显示 30px 彩色皇冠标志、17px 加粗品牌字 Matrius 与右侧搜索、收缩按钮；品牌标志与文字之间留 8px，标志不另加底座或卡片。搜索保持顶部图标入口，不增加独立导航项。搜索与收缩均不做旋转、缩放或位移动画。
- 侧栏收起后，聊天顶栏左侧距边缘 16px 显示单独的展开胶囊按钮：视觉尺寸 48 × 36，点击区域 48 × 44；22px 简洁分栏图标、低对比细边框与统一大号圆角，颜色跟随主题。悬停轻微加深底色与边框，按下提供底色反馈，保持位置与尺寸稳定。胶囊内只保留展开侧栏操作，支持键盘焦点且不显示 Tooltip。
- 侧栏按品牌、主导航、历史分组和底部用户入口分层。主导航包含新对话，后续可增加同级入口；固定在历史滚动区域之外。主项 42px 高、9px 圆角、14px 字号（大屏 15px），使用平面图标与文字；不加卡片边框或图标底座。历史分为「置顶」和「最近」两组，均可独立折叠；组标题至少 36px 高、14px 字号（大屏 15px）与半粗字重，展开箭头紧邻标题右侧，不显示分组数量；历史行至少 36px 高、14px 字号（大屏 15px）、8px 圆角、2px 行间距；触屏点击区域至少 44px。
- 新对话入口使用 lucide-react 的 `SquarePen` 图标，19px、线宽 1.75，颜色跟随侧栏文字。
- 已选中会话使用中性灰底，不能使用用户消息的浅蓝底。颜色由侧栏前景色以 8% 混合到侧栏底色；普通悬停采用 4%。
- 空分组只保留标题与展开箭头，不显示空状态提示文字；置顶与最近两组之间保留 8px 间距。
- 历史会话标题前不显示图标，置顶状态通过分组区分；标题直接左对齐、单行省略，不显示消息数量。仅溢出的标题在悬停或键盘聚焦时，在约 150ms 后以 35px/秒往返展示全称，末尾停留 450ms；离开后恢复省略。开启减少动态效果时改为手动横向滚动。三点菜单在桌面悬停、键盘聚焦或菜单打开时显示，窄屏中直接显示；预留按钮空间，不让标题和行宽跳动。
- 三点按钮旁弹出紧凑的小卡片，卡片左边缘对齐按钮左边缘，靠近视口边缘时自动避让；包含置顶/取消置顶、重命名、删除三个选项；点击外部或按 Esc 关闭。选中重命名后再打开标题输入弹窗，选中删除后再打开确认弹窗。菜单项悬停使用清楚可见的圆角中性底色，删除文字和图标保留危险色。置顶会话单独分组；重命名不能保存空标题；删除需确认。
- 搜索打开独立浮层，匹配标题与消息正文；采用命令面板布局：搜索框即弹窗头部，不显示重复标题栏和底部栏。弹窗宽 640px、距顶约 12vh，窄屏居中，最大高度 560px/74dvh，超出后结果区滚动。行内不显示图标，只有标题、右侧相对时间和下方单行片段；片段去除 Markdown 标记并围绕命中词截取，命中词用主题主色浅底高亮。结果区使用 10px 无箭头细滚动条，按 20 条一批懒加载，滚动接近底部时追加下一批。支持 ↑/↓ 选择、Enter 打开、Esc 关闭；只有鼠标悬停或键盘导航后才显示当前项的中性浅底和细描边，默认不预选第一行，也不显示逐行箭头。无结果时用轻量图标、标题和一句说明；空查询展示最近对话。选择结果后关闭浮层并进入该会话。布局与键盘交互参考 LobeChat CommandMenu（Raycast/VS Code 命令面板模式）。
- 底部用户行不显示卡片边框或设置图标，使用 32px 头像、模式名与浏览器存储说明；整行可点击，悬停增加中性底色，不添加第二个设置入口或侧栏深浅色切换按钮。未登录时主文案固定为「未登录」，副文案说明当前状态，整行仍只负责进入账号设置页，不在此处直接弹出登录框；已登录时显示用户名与账号状态说明，不加右箭头；头像使用主题主色的浅色底。Mock 仍显示「本地模式」且不读取真实登录状态。

## 品牌标志

- 品牌标志是一幅彩色皇冠：金色冠体、红宝石与洋红/青色故障像素。侧栏品牌行、空白新对话页、设置 → 关于卡片统一使用 `public/brand/matrius-color.svg`，保留原始填色，不提供单色或随主题改色的变体。
- 网页 favicon 使用透明底的彩色 PNG；PWA 图标与 Apple touch icon 使用同一幅图案的彩色 PNG，放在深梅色圆角底板上，保证系统图标在深色桌面和遮罩裁切后仍完整。图标文件由 `public/icons/` 与 `assets/images/` 提供，manifest 与 service worker 共用这些路径。不要为界面另画一套简化皇冠。

## 消息与输入框

- 空白新对话页居中显示 42px 彩色皇冠标志、品牌名「Matrius」及其下方的输入框；标志与文字同排，窄屏按 34px / 30px 同步缩小。不显示其他装饰图标、欢迎标语或对话灵感按钮。
- Web 选中单条助手回复正文后显示「引用」浮动操作，不截取思考区或操作栏；拖动选区时不重绘浮动按钮。点击后回到输入框，引用以可移除的两行卡片显示，点击可查看完整原文；已发送消息也保留引用卡片。引用与输入草稿按会话隔离，切换设置后保留，发送失败不清空；发送成功后清空。
- 对话有至少 4 条用户提问时显示对话导航。宽屏右侧以最多 15 条短线表示阅读位置，悬停展开全部提问的目录卡片；窄屏改为顶栏右侧按钮点击展开。列表按提问顺序展示，图片或纯引用消息有回退摘要；点击定位对应提问并暂停流式自动跟随，可用回到最新消息恢复跟随。支持键盘方向键、Home/End、Esc 与点击外部关闭，不显示 Tooltip。
- 用户消息右对齐，使用浅蓝色气泡；颜色由主题主色以 16% 混合到页面背景，深色模式使用相同规则得到低亮度蓝底。文字使用正文前景色。
- AI 回复下方常显复制、赞、踩、分支四个图标，桌面按钮 28px、间距 2px，触屏保持 44px 点击区域；赞与踩互斥，可再次点击取消。用户气泡下方仅显示复制图标，桌面悬停或键盘聚焦时显现，触屏常显。工具栏预留高度，不因显隐导致消息跳动，不显示 Tooltip，保留无障碍名称。最后一条消息的操作栏与输入框之间只保留一层常规间距（约 28px）：末尾消息不再叠加自己的下边距，列表底部内边距也相应收窄，避免动作栏和输入框之间出现空档。用户操作栏与紧随其后的回复（含等待阶段的思考行）之间只留 16px，操作栏本身按 28px 预留并紧贴气泡 4px；两条用户消息之间仍用常规间距。
- 赞/踩绑定具体助手消息并自动保存，切换页面与刷新后保持选中状态。后续提问或重新生成时传给 Agent；单独点击不触发模型请求，也不增加对话里的可见反馈消息。重新生成输出的新版本不继承旧版的评分。
- 消息复制使用完整原文，成功短暂显示勾选，失败通过状态和图标颜色反馈；分支从选中 AI 回复（含本条）复制此前上下文到新会话并切换，保留原会话。
- 助手回答左对齐、无气泡，正文和代码块沿统一内容宽度排版。用户与助手共用 Markdown/GFM 和 KaTeX 渲染；标题、引用、列表与表格通过字号和留白建立层次，表格与块级公式在窄屏内独立横向滚动。
- 思考区直接参照 OpenStudio 的 `src/modules/chat/components/response-process.tsx`、`response-process.module.css` 和 `process-activity-section.tsx` 移植布局，不引入 Lobe UI 依赖。上方统一显示「思考过程」，不出现「生成中」「正在回复」等额外状态文案。无底色、无边框的整行按钮使用与正文回答一致的字号（`--text-body`）、1.5 行高、10px 间距，主色状态图标搭配与标题同字号的耗时和箭头；桌面箭头在悬停/键盘聚焦时显示，触屏常显。等待阶段也能展开，没有内容时留空，不加等待或空状态提示。整轮运行时图标呼吸、文字缓慢高光，减少动态效果时静止；思考结束、工具结束或正文开始均不表示回复完成。计时从发送持续到最终回答结束，只有整轮成功才显示勾选，停止/失败使用独立图标。等待入口与消息正文按同一个 replyId 保存展开状态，收到首段内容、完成或开始下一轮时不自动收起。
- 思考正文默认不挂载 Markdown，用户展开后才渲染；正文沿页面自然展开，不套固定高度的滚动框。回答下方不显示来源区；来源聚合属于后续规划。正在流式写入的那一段用纯文本渲染，停止写入或用户手动展开已完成段落时才按 Markdown 渲染：思考文本常在 1 万字符以上、按 50ms 一批到达，逐批重解析 Markdown 会让高块持续回流，配合贴底滚动看起来像整块闪烁。
- 按实际事件顺序追加「思考 → 搜索 → fetch → 再思考」等步骤，每段思考留在发生的位置，不汇总到顶部，不跨思考段合并工具。搜索与网页读取使用 OpenStudio 同款子折叠区：运行时默认展开、结束时默认收起，结束后仍可手动开合。子区标题使用小号字（13/14px）、11px 状态字，内容左缩进 25px，网页卡片使用 8px 圆角、8px/10px 内边距、标题和域名/URL 两行，列表最多 160px 内滚动。同一次并发 fetch 内的多个 URL 展示在同一个子区，失败/取消保持真实状态，部分读取失败明确提示；空搜索结果明确显示无可用结果。
- 思考段落默认折叠；展开视图里，只默认展开正在写入的那一段，该段结束或进入下一个块时自动收起为单行预览，读者手动开合在该段状态变化前保持。正在写入的那一段用纯文本渲染，停止写入或用户手动展开已完成段落时才按 Markdown 渲染：思考文本常在 1 万字符以上、按 50ms 一批到达，逐批重解析 Markdown 会让高块持续回流，配合贴底滚动看起来像整块闪烁。展开箭头收起时向右、展开时向下。展开内容使用小号字（`--text-small`：小屏 13px、视口至少 1024px 时 14px）的辅助色正文、1.5 行高、25px 左缩进、小节点与步骤间细连线，步骤间距 12px；步骤小标题「思考 / 搜索资料 / 读取网页」与正文同为小号字；展开区末尾的「收起思考过程」与标题行同字号、与步骤行左缘对齐，不缩进到时间线留白内，且只在展开内容高度超过约 420px 时出现，短内容不显示。Markdown 段落间距 .35em，标题统一 1em，不得沿用答案的标题字号与块间距。
- 失败说明和「重试」放在同一个紧凑提示条内，使用淡错误色背景、细边框和统一内边距；说明使用辅助色，重试作为容器内右侧操作，以细竖线分隔，不再独立套第二个按钮边框。窄屏时文案在容器内换行，操作保持在右侧。只有当前会话末条失败回复、且该会话空闲时显示重试；发送新消息后只保留旧错误说明。
- 代码块顶部显示语言，右侧只显示复制和收起/展开图标，不显示操作文字；默认展开，复制成功短暂显示勾选图标。操作保留键盘焦点和无障碍名称，触屏点击区域至少 44px，不显示 Tooltip。代码原文可横向滚动，高亮颜色仅随浅色/深色模式切换。
- 输入框使用轻背景、细边框与固定圆角，不加明显阴影。焦点只改变边框颜色，不改变边框宽度或布局。
- 输入框从 2 行起步，最多扩展到 8 行，再由输入框内部滚动。底部工具栏整体靠右，模型选择器紧邻发送/停止按钮左侧，间距 10px；这个位置保持固定，视觉优化不改变操作顺序；触控高度至少 44px，使用清晰可见的 18px 箭头。选择器收起时在模型名前显示 SVG 图标，并同时显示当前模型名和当前思考强度，强度是不带底色的辅助色小字、与模型名同处一行并由它先省略；不给强度加胶囊或边框，否则会被当成模型旁边多出来的一个控件。点击后在选择器上方展开非模态列表，卡片宽度固定 248px（窄屏按视口宽度收缩），不随模型名长短变宽，模型名仍在单行内省略。按 Provider 小标题分组模型，每个模型前显示可跨平台复用的服务商/模型标记。仅在已选中可用模型时，列表末尾显示「思考强度」及当前档位；空列表不显示这项及分割线；该行的形状、高度、圆角与悬停底色必须和模型行完全一致，上方保留一条分割线与模型列表分开；分割线是独立的一条线、两侧各留间距，不能做成该行的上边框——那样它会跟这行的悬停底色共边，看起来像粘在一起。靠右指箭头区分它是进入子页而不是选中项。点击后在同一弹层内切换到覆盖模型列表的强度选择页，可返回模型列表，不另开浮动子菜单。强度相关的文案全部用中文（思考强度、默认/低/中/高），存储标识仍是英文枚举值，两者不要混用。
- 输入非空内容后，发送按钮下一帧立即启用；清空或仅空白时立即禁用。生成中同一按钮位置变成停止。
- 桌面键盘 Enter 发送，Shift + Enter 换行；移动 Web 软键盘需保留换行，通过发送按钮提交。中文输入法组合过程中 Enter 用于确认候选，不误发送。这些快捷键不在输入框下方显示。
- 发送后清空输入并保留焦点。停止生成保留已生成内容；操作侧栏不应让正文突然跳动。
- 发送前的配置、附件校验等错误显示在对话顶部的横向小卡片中：最大宽度 780px，与内容对齐，约 48px 高；仅提示图标、正文和关闭按钮，浮层不挤动布局、不抢焦点。实际请求失败在对应回复下显示简短错误，主动停止是中性的「已停止生成」，都不附加重试或重新生成按钮。刷新恢复的半截回答明确说明页面重新加载造成中断；保留已有内容和原问题，后续提问不删除上一轮。
- 顶部提示卡片显示 5 秒后自动关闭，也可手动关闭；提示内容变化时重新计时，普通输入与流式更新不延长显示时间。
- 输入框附件入口始终可点击，不随模型选择、图片能力或生成状态禁用。选取或粘贴文件后先暂存附件，发送时统一校验格式、数量、大小与模型图片能力；当前仅可发送 PNG、JPEG、WebP、GIF 图片，每条最多 4 张、每张不超过 10MB，其他文件发送时通过顶部提示卡片说明暂不支持。
- 附件入口采用无边框回形针：36px 视觉按钮、22px lucide 图标与统一 1.75 线宽，前景色保持清晰；悬停、按下和键盘聚焦以圆角中性轻底色反馈，点击命中区扩展到 44px。不显示操作 Tooltip，不添加缩放或旋转动画，颜色跟随主题。
- 待发送附件参考 openstudio 的单行附件条：180px 宽卡片、10px 圆角、6px 内边距、7px 列间距，左侧 30px 图片缩略图或按扩展名区分的文件图标，中间两行显示 12px 文件名和 11px 文件大小，右侧 24px 描边圆形移除按钮；卡片之间间距 8px，多文件横向滚动，不换行撑高输入框。使用主题的轻背景、细边框与主色浅底图标区，触屏扩大操作命中区。附件区与文字输入区之间用细分割线隔开；只有图片缩略图触发预览，移除按钮独立。附件悬停显示完整文件名是操作 Tooltip 禁用规则的例外。图片点击打开全屏预览：参考 openstudio 的居中图片与无标题栏布局，预览容器透明，半透明遮罩透出原页面，图片保持比例并适应视口；仅保留右上角关闭按钮，支持点击图片外遮罩、Esc 退出及关闭后焦点恢复，文件名仍提供无障碍名称。
- 消息区离开底部后，在输入框正上方靠右显示 36px 圆形「回到最新消息」按钮：右边缘与发送按钮右边缘对齐（距输入框右边缘 16px，不贴边），与输入框上沿只留 8px 间距，比原先的居中浮层贴得更近：浮层底色、细边框、轻阴影，回复生成中显示旋转的环形加载图标，空闲时显示向下箭头，不显示文字，保留无障碍名称且不显示 Tooltip；开启减少动态效果时改为呼吸动画。滚动位置在底部约 12% 视口高度以内算作跟随，新内容和流式输出自动贴底；由滚轮向上、触摸下拉或翻页键主动回看后立即停止跟随，不再被新内容拉回底部。点击按钮平滑滚回底部并恢复跟随，跟随中不显示按钮。

- 模型标记使用 theSVG（`@thesvg/react`）彩色 SVG，保留品牌原色、各路径填色与渐变；展开列表和收起按钮共用同一组件，优先按模型 ID/名称识别模型品牌，再匹配服务商名；无法识别时显示统一模型芯片图标，不加载外部图片。

## 字体、圆角与选区

| 场景 | 字体与规格 |
| --- | --- |
| 正文 | Inter，中文回退 Noto Sans SC；15px，大屏 16px，行高 1.6 |
| 侧栏标题 | 正文系列，14px，大屏 15px；置顶/最近使用半粗字重 |
| 代码块 | JetBrains Mono，中文回退 Noto Sans SC；13px，大屏 14px，行高 1.55 |
| 基础圆角 | 大号圆角 20.8，来自 Twitter 的 1.3rem 基准 |
| 其他圆角 | 小号 16.8、中号 18.8、大容器 24.8；统一由共享形状常量管理 |

- 字体随应用打包，不依赖系统字体或在线字体请求。
- 用户消息与助手回答使用统一的文本选择与复制适配。Web 目标为同一回答跨块连续选择；跨独立组件选区需单独验证。Web 正文使用文本光标，按钮使用点击光标。
- 中英文和代码按各自文字规格使用固定行高；选区色在主题层预合成为不透明色，避免不同容器底色改变选中效果。
- 行内代码保留在正文文本流中，用等宽字体区分；避免嵌入导致复制丢字的独立组件，不叠加遮挡选区的文字底色。
- 代码语言标签、复制和折叠按钮不参与正文选区，复制不能混入工具栏文字。

## 修改与验证

- 先调整对应组件或统一 token，再更新本文；不要在不同页面复制同一套尺寸常量。
- 检查浅色、深色、桌面与窄屏。特别检查条目宽度、弹窗、焦点、菜单可达性、输入法、选区和滚动轨道。
- 静态检查与相关测试按 [开发与验证](development.md) 执行。浏览器/Web 实测和截图不作为常规 UI 修改步骤；仅在用户明确要求时执行。
- 当前 Web 已实现会话管理、搜索、输入框、字体和 10 套配色；已接入本地模型流式生成，生成时发送按钮变为停止；未配置模型时提示进入模型服务，保留输入草稿，不生成模拟回复。Web 对话、外观偏好、模型配置与模型 API key 已存入浏览器（密钥边界见[客户端约定](client.md)），移动 Web 适配与跨段落选区仍需实测。

## 账号、登录与管理

- 账号是独立设置分组「账号」，排在设置导航最上方，不放进「应用」；数据同步是账号页的一部分，不占独立设置项。账号页未登录时展示「未登录」、登录入口和登录收益（当前为跨设备同步）；登录后自上而下依次是资料卡（头像、用户名、账号徽章）、数据同步、管理控制台入口（仅管理员）、账号安全，账号安全始终在页面最下面，不再重复登录收益。资料卡下方不重复说明登录状态的存储方式。登录状态为验证中或服务器不可用时分别给出状态说明与重试，不把失败伪装成未登录。
- 登录入口只在设置 → 账号页：未登录状态卡片的「登录」按钮打开登录弹窗，侧栏底部的用户行只负责进入设置，不直接弹出登录框。弹窗包含账号、密码两个字段，左侧图标、右侧密码显隐按钮，底部整宽主按钮。首次登录必须改密时，同一弹窗切换到「设置新密码」步骤，保存后才关闭。用户名或密码错误只在登录弹窗内显示一次，不写入账号页的常驻状态；关闭弹窗或重新打开时不重复出现。
- 「账号安全」用一行一项的列表，固定放在账号页最后：密码行右侧「修改密码」打开独立弹窗，不在页面上内联三个密码框；登录状态行右侧「退出登录」先打开确认弹窗。修改成功后在资料卡下方给出短暂的成功提示；必须改密时在列表上方显示提示条和「立即修改」，并自动打开改密弹窗。
- 「数据同步」只在账号已验证且完成首次改密后出现，以折叠列表呈现：标题行固定显示上次同步时间（形如「上次同步：今天 14:05」，从未同步时为「尚未同步」）和展开箭头，点击展开或收起，箭头随状态旋转 180°。展开后的类别列表有固定最大高度（约 224px），超出时在列表内部滚动，不把页面撑长；滚动条使用与整体一致的细样式。
- 同步类别为聊天记录、已读和未读、个人设置、界面外观四项，每项用一句日常说法说明同步后会怎样，整行可点击勾选，勾选后自动保存。类别行之间不用分隔线，每行的圆角和悬停底色各自成立，视觉上接近侧栏会话行；列表内边距与行间间距保持紧凑。不再提供图片和文件类别，因为当前同步不包含附件内容。
- 展开面板底部显示同步状态（最近同步时间或失败原因）和「同步」按钮，按钮点击立即同步；同步中禁用按钮并显示进行中的状态。除手动同步外还会后台自动同步，不要把自动同步描述成未实现。
- 管理控制台 `/admin` 是独立整页工作台，不复用聊天侧栏，也不提供返回应用的链接。顶部栏固定显示品牌、当前管理员与退出；内容区最大 1120px，依次是标题与操作、四张统计卡（全部用户、管理员、待改密码、已停用）、可搜索的用户表格。整页使用与设置页相同的字体、圆角、细边框和浅色表面，不恢复居中窄卡片布局。
- 管理后台固定使用 Modern Minimal 主题，不跟随聊天界面的主题或深浅色设置；后台顶栏提供独立的深色/浅色切换按钮，选择只保存在管理后台本地。顶栏按钮与后台其余控件使用同一主题变量。
- 用户表格每行显示头像、用户名、角色徽章、状态徽章、创建日期与右侧图标操作；重置密码、停用/启用都先打开确认对话框，停用自己不可用。创建用户与重置密码完成后，在对话框内一次性显示初始密码并提供复制，明确提示关闭后无法再次查看。
- 管理登录页是独立的居中登录卡片，不再与用户管理混在同一页：品牌标记、标题、说明和登录表单自上而下排列，验证已有管理员会话时显示加载状态。管理页不提供返回应用的入口。

## 设置导航

- 个性化为独立设置分类，显示自定义指令、称呼、职业与更多个人信息，沿用主题表单样式并自动保存。多行输入框禁止手动拖拽，随内容从 112px 自动增高至最多 240px，超过后在框内纵向滚动，删除内容或改变可用宽度时重新适应。长文本提供长度限制与计数，说明下次请求生效及内容会发送给所选服务商；Mock 提示刷新重置。当前不展示记忆开关或管理入口。
- 个性化多行输入框由外层保留边框、圆角和内边距，内部 textarea 单独滚动；滚动条沿用应用统一轨道和上下箭头，与外框上下及右侧留出间距，避免覆盖边框或圆角。焦点通过外层 `focus-within` 改变边框颜色，内层不再绘制焦点轮廓，整体高度仍为 112–240px。
- 设置首页只展示项目目录与当前值，提供搜索框；搜索即时匹配项目名称、说明和关键词（包括主题名称），无结果时提供清空与查看全部入口。
- 显示模式与配色主题合并到“外观”子页；模型服务与关于分别进入独立子页，每一级都可返回上一页或直接回到对话。所有设置页面保持独立全页布局，不包在聊天侧栏内。
- 正式工作区与 Chat Mock 共用设置组件和导航结构；Mock 设置与聊天共用内存状态，刷新重置，不能跳到正式设置或写入真实数据。
- 模型服务子页的服务商列表默认全部折叠，每张卡片占一行。卡片只有标题行和模型列表两部分，中间不加信息栏或操作栏。折叠是纯视图状态，不写入存储，刷新后回到全部折叠。
- 标题行为两行：第一行是服务商名称、模型数量徽章，以及全部四个操作——「获取模型列表」「手动添加」「编辑」「删除」；第二行是「协议 · Base URL · 鉴权状态」。四个操作不随展开出现，编辑与删除作用于服务商本身，获取与添加作用于模型列表，展开与否都要用得到；它们挤在第一行也不会把信息行压窄，因为信息行独占整行。四个按钮同处一行，两个文字按钮保持常规次要按钮的外观（细边框加浅底色），不为了腾地方去掉轮廓——去掉轮廓的按钮不再读作按钮；只用比别处更紧的内边距和高度来收宽度。标题行不标「当前模型」：拿不准它说的是服务商还是模型，而设置页整体都不标记当前模型——当前模型由输入框旁的模型选择器显示和切换，这里再标一遍只会多出第二处说法。信息行同样不写「当前：某模型」。Base URL 过长时换行显示，不截断鉴权状态。
- 整条标题行是一个点击目标：展开按钮铺满整行压在文字下层，而不是只包住文字——按钮包不住四个操作，而只包住文字的按钮会让悬停高亮和焦点圈在按钮处断开。四个操作叠在它上层，各自保留点击。展开箭头只作装饰、不接收点击：它旋转后因为 transform 会被当作定位元素抬到遮罩层之上，否则展开后那一下「收起」会落在图标上，整行看着就是点了没反应。窄屏时名称独占一行、四个操作右对齐折到下一行，箭头移到右上角。
- 展开后的模型列表有高度上限（560px 与视口高度的 64% 取小者）：到顶之后只让列表自身滚动，服务商标题行留在原位不动，一张模型很多的卡片不会把后面的卡片顶出屏幕。上限加在列表容器上而不是整张卡片上，模型少的卡片仍然只占内容那么高。
- 模型行只有模型本身和它的两个操作——编辑与删除，既不设「使用」按钮，也不用勾选标出当前模型：显示和切换当前模型都在输入框旁的模型选择器里，设置页再放一份就是同一件事配两个入口，行首多出一列图标还会把每行挤窄一点。模型行不做成整行点击目标——行里的模型 ID 是常被选中复制的内容，整行可点会把这件更常用的操作挡掉。模型行之间不用分隔线，每行用独立的圆角和悬停底色区分，列表容器留出内边距；编辑与删除按钮仍保留自己的轮廓。
- 「获取模型列表」打开独立对话框，不内联撑开卡片。等待、筛选、添加与失败提示都在对话框内完成：标题说明是哪个服务商，可「重新获取」，底部「完成」关闭；模型列表是对话框内唯一的滚动区域（标题、说明、筛选框与底部按钮固定不动），并按名称或模型 ID 提供筛选框。关闭后不保留上次结果，再次打开重新请求。
- 服务商与模型的编辑表单使用对话框，删除服务商或模型先经确认对话框，不使用浏览器原生确认框。编辑模型时「支持图片输入」用胶囊开关呈现：说明文字在左、开关贴右，开关形状与账号页「网页搜索」一致，不再使用勾选框；只有开关本身可点击，点击说明文字或整行不会改变状态。接口是否需要 API key 仍用勾选框。
- 表单中的单选下拉框自绘，不使用原生 `select`：原生控件把弹出列表、系统字体和箭头交给操作系统，无法跟随主题与圆角。收起态与同级输入框完全同尺寸（细边框、12 圆角、14 字号），右侧用主题的展开箭头代替系统箭头，展开时箭头旋转 180°；焦点只改边框颜色、不画焦点圈，与同级输入框一致。选项面板与输入框同宽并紧贴其下方；它与所在对话框同为浮层底色，因此边缘和阴影要独立承担“浮起来”的观感——边框向正文色混合以在明暗两套主题下都成立，阴影分两层。焦点在收起态由箭头键直接展开。选项行只放选项名，不加说明文字：选项之间靠名称区分，解释会拖慢扫读并撑高面板。名字用与收起态相同的字号，选中时文字不因面板收起而变化；当前项右侧显示勾选图标并保留浅色底。支持上下方向键、Home/End 与 Esc 关闭并回到触发器。

- 设置保持独立整页，目录与子页都不添加分类侧栏、横向分类导航或位置路径。返回与 Home 位于页面左上角（桌面距左 24px，窄屏 16px），组成一个浅底细描边胶囊，中间以短竖线区分；20px 图标、40px 圆形按钮区域（触屏至少 44px），悬停和按下以中性底色反馈；设置内容的位置不随按钮调整；返回实际上一页，无历史时回父级，Home 直接返回聊天。保留工作区和草稿，不显示 Tooltip。

- 设置目录采用按组收拢的 12px 圆角列表，组内用细线分隔；图标底座 32px、无额外描边。内容区最大 840px，桌面内边距 48px；标题 26px，搜索框 9px 圆角。输入区恢复原有布局和控件形状：模型选择固定在圆形发送按钮左侧并整体靠右，不随侧栏或设置页改版改变。

设计参考：[LobeHub 侧栏导航源码](https://github.com/lobehub/lobehub/blob/canary/src/features/AgentSidebar/Header/Nav.tsx)、[Linear 设置页](https://linear.app/changelog/2024-12-18-personalized-sidebar)。只采用导航分层、密度和成组列表，不引入其业务功能。

- Web 字体统一使用 `--text-body/ui/small/caption` 四级整数尺寸：小屏 15/14/13/12px，视口宽度至少 1024px 时为 16/15/14/13px。辅助文案不再以 11px 渲染；不强制灰度抗锯齿，不用 transform 或 zoom 放大文字。侧栏辅助色提高到前景色 70% 混合，确保分组标题更易读。
