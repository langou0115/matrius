## 当前范围

旧工程位于 `../matrius-old`，Flutter/Dart 界面需用 React 组件重写。当前项目已有 Expo SDK 57 与 Expo Router，无需重新初始化工程。当前按 Web 优先推进，移动端后续适配。

## 已完成

1. 迁移产品与开发文档，明确 Agent Runtime 在客户端本地运行，网络搜索与文件处理在云端执行。
2. 替换模板导航：移除 Explore 与 Home/Explore 标签栏，使用 `/` 聊天和 `/settings` 设置路由。
3. 将 Web 页面放到 `.web.tsx`，业务组件放在 `src/app/` 外；移动端暂留说明页。
4. 迁移字体资源和 10 套 tweakcn 配色，保留 Twitter 默认配色，支持浅色、深色与跟随系统。主题切换只改变配色。
5. 重建聊天外壳：侧栏、收起/展开、新对话、欢迎页、输入框与消息区。
6. 实现会话的新建、切换、搜索标题与正文、置顶、重命名及确认删除。
7. 实现独立全页外观设置；清理模板组件与 reset-project 脚本。
8. Web 工作区接入 IndexedDB，启动恢复数据，顺序保存对话与偏好，存储错误和多标签页版本冲突可见。

## 交互与边界

- 输入框支持中文输入法、Enter 发送、Shift+Enter 换行；建议按钮将提示词填入输入框，不自动发送。
- 搜索支持 Ctrl/Cmd+K 打开，Esc 关闭；弹窗使用浏览器原生 dialog 处理模态焦点。
- 正常模式没有种子会话或模拟 AI 回答，发送后保存用户输入至当前浏览器，并说明模型尚未连接。开发地址的 `/mock` 目录可进入 `/mock/chat`、`/mock/settings` 独立预览，仅用于界面调试，不修改浏览器真实记录。
- 未接入认证，保持本地模式，资料库、文件上传和网络搜索入口不显示。
- Web 刷新恢复对话、消息、置顶与外观偏好；未发送草稿仍仅保留在页面会话。清除网站数据会删除本地记录。App 后续存入手机本地数据库，旧版数据导入另行设计。
