## 交互与边界

- 输入框支持中文输入法、Enter 发送、Shift+Enter 换行；建议按钮将提示词填入输入框，不自动发送。
- 搜索支持 Ctrl/Cmd+K 打开，Esc 关闭；弹窗使用浏览器原生 dialog 处理模态焦点。
- 正常模式没有种子会话或模拟 AI 回答，接入本地 pi-agent-core Runtime，配置模型后发送真实请求并保存流式回复，支持停止、错误重试与历史上下文。开发地址 `/mock` 是预览索引页，可进入 `/mock/chat` 查看 109 个会话、1730 条消息的聊天渲染样例；聊天预览保留完整界面和设置入口，设置通过 `/mock/chat/settings` 复用正式组件；预览修改不写入浏览器真实记录。
- 客户端数据仍保持本地模式，账号登录与功能开关已接入，云端数据 API 尚未接入；资料库、文件上传和网络搜索入口不显示。后端接口已就绪，见[后端架构](backend.md)。
- Web 刷新恢复对话、消息、置顶与外观偏好；未发送草稿仍仅保留在页面会话。清除网站数据会删除本地记录。旧版数据导入另行设计。
