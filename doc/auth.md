# 认证与用户管理

[文档索引](README.md)

## 认证

认证保持简单。

### 服务端初始化

服务端部署后，当 PostgreSQL 中没有任何用户时：

```text
管理员访问服务端
    ↓
创建第一个管理员账号
    ↓
保存管理员账号
    ↓
初始化入口永久关闭
```

只有第一个管理员可以通过初始化流程创建。一旦存在用户，该入口不可再次使用。

**注意区分**：这是服务端初始化，与客户端的首次启动无关。客户端首次打开**不需要**创建管理员，直接进入本地模式即可。

### 创建用户

管理员在管理页创建用户：

```text
填写用户名
    ↓
初始密码设为 `<username>@123`
    ↓
哈希后保存
    ↓
仅本次返回初始密码
```

禁止保存明文密码。初始密码只展示一次。

### 首次登录

新用户首次登录必须修改密码。

建议的用户字段：

```text
id
username
password_hash
is_admin
must_change_password
created_at
updated_at
```

流程：

```text
用户登录
    ↓
must_change_password = true
    ↓
强制修改密码
    ↓
must_change_password = false
    ↓
进入对话
```

### 管理页

管理页初期只需要：

```text
用户列表
创建用户
重置密码
停用 / 删除用户
```

管理页有独立的登录入口和会话范围，不复用普通用户的会话。

重置密码应当：

```text
重置为 `<username>@123`
设置 must_change_password = true
仅本次返回新密码
```

在明确需要之前，不要引入：

```text
RBAC
组织
租户
复杂权限系统
```
