# 产品与开发边界

[文档索引](README.md)

Matrius 是可自行部署的单用户 AI 对话应用，提供 React Web 与 PWA。
每个部署只有一个所有者、一个工作区。独立的多用户/实例管理属于其他项目，本工程短期不实现。

## 唯一运行方式

- 打开页面先验证实例会话，未登录时只能登录；退出后回到登录入口。
- 会话、消息、已读状态、记忆、个性化、外观、网络工具偏好、文件与 Token 用量以服务端为唯一事实源。
- 不提供匿名本地工作区、本地/云端切换、浏览器聊天缓存、离线队列或增量同步。
- 模型服务配置与 API key 继续保存在当前浏览器；不持久化到服务端。不同设备需要各自配置。
- Agent Runtime 仍在浏览器运行，后端提供工具 API；模型中继位于 Web 服务。关闭网页会中断客户端任务。
- 本机开发与 Docker 运行同一套业务逻辑，区别只是数据目录与部署方式。
- PWA 可缓存静态外壳，业务数据和模型请求需要联网。

## 核心功能

多模型流式对话、思考与工具过程、引用、分支、搜索、个人记忆、个性化、资料库、文档工具和 Token 用量。
开发预览仅在 `/mock/*`，使用独立内存数据，不构成另一种产品运行模式。

## 技术边界

React 19、TypeScript、Vite 8、React Router 7；FastAPI、SQLAlchemy、Alembic、SQLite WAL。
单 API worker；限流、缓存和文档草稿元数据保存在进程内。
不引入多用户角色、组织、租户、多 Agent 编排或外部实例管理功能。
新功能使用统一能力清单，不按用户名或角色开放。

## 旧数据升级

迁移绑定唯一所有者，旧的用户管理 API 与页面已删除。
为保留已有会话和文件，数据库中的历史 `users` 行与 `user_id` 外键暂留兼容；仅 `instance.owner_id` 指向的所有者能够登录和访问资源。
旧库有多个账号时，必须用 `INITIAL_ADMIN_USERNAME` 指定现有账号；不自动混合其他人的数据。
旧浏览器聊天数据不删除，也不自动上传，应用不再加载它。
详细规则见[认证](auth.md)和[存储与数据](data.md)。
